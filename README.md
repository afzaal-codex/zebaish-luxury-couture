# ZEBAISH — Haute Couture & Luxury Pret Web Application

A high-end, responsive luxury eastern fashion e-commerce web platform built with **React.js**, **Tailwind CSS**, and **Vite**. Features slide-out cart drawer, collection filter drawer, lookbook gallery, and streamlined checkout.

---

## 🌟 Key Features

1. **Brand Identity:** **ZEBAISH** (*Haute Couture & Luxury Pret*) with custom luxury butterfly insignia.
2. **Typography Standards:** *Cormorant Garamond* & *Cinzel* for headings, *Montserrat* for micro-typography, prices, and buttons.
3. **Template Precision:**
   - **Top Announcement Bar:** Rotating banners with `< >` controls.
   - **Navbar:** Sticky header with `MENU` drawer, butterfly emblem, currency switcher (`PKR`, `USD`, `GBP`, `AED`, `EUR`, etc.), user account, search overlay, and bag badge.
   - **Mobile-Optimized Header:** Clean mobile view displaying only `MENU`, Logo, Search, and Cart Bag.
   - **Search Bar Overlay:** Full-width search bar `SEARCH FOR...` with instant real-time results.
   - **Collection Page ("CHIFFON ESSENTIALS '26"):** Clean `SORT BY` and slide-out `FILTER` drawer (Color, Fabric, Price Range) with single-column mobile lookbook stream.
   - **Zero Image Gap:** Fixed aspect-ratio containers ensuring all garment images fit flush with 0 awkward white/gray spaces beneath.
   - **Product Detail Page (PDP):** Multi-photo lookbook carousel with dots indicator, `Unstitched` / `Stitched` toggles, lining options, quantity controls, size chart popup, accordion specs, and recommendations.
   - **Slide-Out Cart Drawer:** Real-time quantity adjustments, free shipping progress bar, expandable order notes, and `CHECKOUT • RS 6,950` action.
   - **Shopify-Style 2-Column Checkout:** Contact, delivery fields, payment method toggles (Card & COD), and voucher discounts (`ZEBAISH10`).
   - **Customer Policies Modals:** Privacy Policy, Return & Exchange, Customized Sizes, Shipping.

## 🚀 How to Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build for production
npm run build
```
